Fatos operacionais que já custaram debug (não re-descobrir):
- **Escopo de unidade não está no JWT**: todo usuário criado em runtime precisa de ≥ 1 linha em `identity_user_unit_scopes` (`ALL`/`ORGANIZATION`/`FARM`), senão 403 `forbidden_unit_scope` no middleware **antes** da política de permissão. Com escopo FARM único, a farmId é auto-selecionada (sem parâmetro). Seed dá `'ALL'` só aos usuários existentes. **O middleware valida escopo pelo header `X-Farm-ID`; a query `farmId` é apenas filtro de listagem** em todos os endpoints de pecuária (comportamento de plataforma preexistente; LIMITES #48) — asserir 403 de unidade via query falha.
- **Precedência de operadores Postgres**: `->>` e `||` têm precedência **igual** e associam à esquerda — `data->>'a' || x || data->>'b'` vira `((data->>'a') || x) ->> 'b'` (erro `text ->> unknown`). Sempre parênteses por extração em cadeias.
- **Dapper × records grandes**: registro com ctor primário de muitos parâmetros (com opcionais) pode falhar materialização em runtime ("no matching constructor") mesmo com colunas todas presentes — padrão da base para listagens é **linha POCO + `ToDto()`** (ex.: `AnimalDetailRow`).
- **Postgres: parâmetro NULL sem `DbType` vira 42P08** em predicados `@P is null` — tipar todos (o P2 descobriu este padrão latente em 5 sítios de listagem de pecuária: `DateOnly?` nulos → 500 em toda chamada sem datas; corrigido com sentinels Min/MaxValue — ao escrever nova listagem com filtros de data opcionais, seguir o mesmo padrão). Violação de FK → 409 genérico (por isso códigos amigáveis explícitos, ex.: `livestock.tag_not_unique`). Inferência de ON CONFLICT em índice parcial exige expressão exata.
- **Postgres 18 imprime boolean como `true`/`false`** no psql (antes `t`/`f`) — asserções de harnesses sobre boolean devem usar `CASE WHEN col THEN 'true' ELSE 'false' END` (ou aceitar ambos). Descoberto no E2E do P2.
- **Versionamento do schema**: migs ≤ 135 registram versões de **release** (mig 135 = linha `11.25.0` em `platform_schema_versions`); migs 136+ usam número de arquivo (`136.0.0`…`142.0.0`). `max(version)` **léxico** nessa tabela é enganoso (`'9.8.0' > '142.0.0'` como string; há também versões com sufixo `-rc` que quebram cast inteiro) — ordenar numericamente por `split_part`.
- O JWT embute as permissões no login: concessão de permissão/módulo por banco exige **re-login** para valer. O middleware de acesso efetivo (PermissionAuthorization) consulta o banco por request; a autorização de papel ao salvar perfis filtra por módulos contratados no login.
