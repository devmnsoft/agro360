# API externa
Aplicações têm status, rate limit e escopos explícitos (`producers.read`, `properties.read`, `fields.read`, `lots.read`, `orders.read`, `contracts.read`, `certificates.read`, `fiscal.authorized.read`, `requests.write`, `quotations.write`, `logistics.events.write`, `evidence.write`, `traceability.read`, `marketplace.read`). A chave `ag360_…` aparece uma única vez; só prefixo e SHA-256 são persistidos. Rotação cria nova chave e revoga a anterior. `POST /api/api-keys/{id}/revoke` invalida a chave. O middleware do parceiro deve resolver tenant pela aplicação, conferir hash/status/expiração/escopo e responder 401, 403 ou 429 em envelope padronizado sem registrar payload sensível.
