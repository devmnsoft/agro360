# Implantação assistida

Crie o projeto escolhendo o cliente pelo nome — nunca digitando UUID — e informe período e responsável. São criadas, em ordem: Kickoff, Levantamento, Configuração inicial, Migração, Treinamento, Homologação, Go-live, Estabilização e Encerramento.

Uma fase requer checklist concluído ou evidência textual. Go-live bloqueia sem Homologação concluída; reabertura e salto de fase obrigatória exigem justificativa. Riscos altos e pendências críticas devem criar alertas operacionais. O progresso exibido deriva das fases persistidas.
