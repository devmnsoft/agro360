# Portal de Parceiros
Parceiros possuem CPF/CNPJ normalizado, tipo, contato, cobertura, segmentos e status global. Cada acesso liga parceiro e tenant com escopos, módulos e expiração. Parceiro bloqueado não recebe concessão; cliente autorizado pode revogar seu vínculo. Consultas nunca aceitam tenant informado pelo cliente fora do contexto autenticado.
