# Programas de produção integrada
Programas controlam regras, calendário, insumos recomendados, metas, padrão de qualidade, participantes, conformidade e status. São aceitas as cadeias açaí, tucupi, cacau, leite, carne, grãos, mandioca/farinha e produto genérico. Use `/api/production-programs` e `/{id}/members`.
