# Pré-análise de crédito rural
Coleta produção, histórico financeiro, documentos, garantias informativas, finalidade, valor e prazo para parecer interno. O status não significa concessão de crédito. `ICooperativeService` é a fronteira atual; uma integração bancária futura deve implementar contrato próprio, consentimento, segurança e homologação reais, sem respostas simuladas.
