# Agro360.Mobile.Core

Núcleo independente de UI para o aplicativo .NET MAUI Android/iOS/tablet.

Esta entrega define o contrato Offline-First, Local Outbox, estados de sincronização e política de conflitos. Dados financeiros, estoque, sanidade e permissões nunca usam “último a salvar ganha”. O shell Web também é instalável como PWA; o host MAUI será incorporado na Fase 15 quando o pipeline possuir os workloads Android/iOS.
